# 设计说明

本文记录需要跨模块对齐的设计决策。阈值与容量类参数在电池规格书确定后补入 `config/`。

## 1. 保护状态机

### 状态迁移表

| 当前 | 事件 | 下一状态 | 动作 |
|---|---|---|---|
| 正常 | 任一量越过告警阈值 | 告警 | 写故障码，上报 `prot_state = 1`，限流 |
| 正常 | 任一量越过保护阈值 | 保护 | 断开主回路，上报 `prot_state = 2` |
| 告警 | 全部回到告警阈值 − 迟滞 | 正常 | 清除告警故障码 |
| 告警 | 任一量越过保护阈值 | 保护 | 断开主回路 |
| 保护 | 全部回到保护阈值 − 迟滞 | 恢复 | 保持断开，延时确认 |
| 恢复 | 稳定运行 T 秒且无新告警 | 正常 | 合闸，恢复充放电 |
| 恢复 | 期间再次越限 | 保护 | 重新断开，计时清零 |

### 为什么需要迟滞

阈值附近叠加采样噪声，没有迟滞带会形成高频状态翻转：继电器反复吸合、
故障码疯狂刷写。迟滞量取「噪声峰值 × 2」，具体值由实测采样数据确定。

### 为什么恢复要延时

保护动作后立即恢复，若故障真实存在会变成「断开—恢复—再断开」的循环，
对主回路接触器寿命伤害很大。延时确认相当于一次软件滤波。

## 2. 采样与滤波

- ADC 由定时器触发，采样周期固定，避免与 CAN 上报耦合
- 一级滑动平均抑制随机噪声，窗口长度取 8
- 二级一阶低通抑制高频毛刺：`y[n] = α·x[n] + (1−α)·y[n−1]`，α 取 0.2
- 上报值使用滤波后的结果，保护判断使用原始值与滤波值**双路**：
  原始值响应快但易误触发，滤波值稳定但滞后，两者同时越限才动作，兼顾速度与可靠性

电流采样需要区分充电与放电方向，采用带偏置的双极性接法，零点在量程中点。

## 3. SOC 估算

### 安时积分

```
SOC(t) = SOC₀ − (1 / Q_rated) · ∫ I(τ) dτ
```

- `I` 充电为正、放电为负
- 离散实现：`SOC[k] = SOC[k−1] − I[k] · Δt / (3600 · Q_rated)`
- `Q_rated` 单位 Ah，`Δt` 单位秒

积分法的固有问题是**误差累积**：采样偏置、`Q_rated` 随温度与老化变化、
库仑效率损失，都会单向累积且不可自愈。

### OCV 修正

电池静置足够长时间后，端电压趋近开路电压（OCV），而 OCV 与 SOC 有单调对应关系。
用此时的 OCV 查表得到一个可信的 SOC，直接覆盖积分值，把累积误差清零。

修正触发条件（三者同时满足）：

1. 电流绝对值持续低于静置阈值超过 `T_rest`
2. 距上次修正超过最小间隔，防止频繁覆盖
3. 温度在查表有效范围内，超出范围不修正

### 局限与边界

- OCV 修正依赖静置，设备连续运行时长时间得不到修正机会，误差会持续累积
- 查表精度受电池老化影响，实际容量衰减后 `Q_rated` 需要随 SOH 更新，本版本不实现 SOH 估算
- 低温下 OCV 曲线平坦，查表分辨率差，此时以积分值为主
